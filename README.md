# Statistical Analysis

A statistical analysis tool for crypto and equity markets. Surfaces probabilistic insights about **when** highs/lows form and **how far** price has moved — so traders can make faster, data-backed decisions.

## Features

- **Time** — When are highs/lows typically set? Reversal vs. continuation probability by session time.
- **Distance** — How does today's range compare historically? Extension vs. reversal probability.
- **Summary** — Combined view across two timeframes with Confidence Targets.
- **Overview** — All assets, all stats, one sortable table. Spot opportunities in seconds.
